# Human Body

Human Body is the gateway to a collection of independent, educational science modules about the human body. Each module has its own experience and deployment while sharing a common visual identity and a commitment to clear, responsible science.

## Modules

| Module | Subject | Status |
| --- | --- | --- |
| [TelomereClock](https://telomereclock.pages.dev/) | Telomeres, cell division, and ageing | Available |
| [Heartbeat Lab](https://heartbeat-lab.pages.dev/) | Heart, circulation, and blood pressure | Available |
| Neuro Map | Neurons, synapses, and memory | Coming soon |
| Immune Arena | Innate defences, antibodies, and vaccines | Coming soon |

The collection portal links to modules; it does not combine their code or simulations. Each module can be developed and released independently.

## Run locally

This portal is a static HTML site and has no package dependencies. Open `index.html` in a browser, or serve this directory with any local static HTTP server.

## Deploy

The portal is hosted on Cloudflare Pages and connected to this GitHub repository. It does not require a build step; Pages serves the repository root. Push changes to `main` to trigger a deployment.

## Project structure

```text
index.html   Bilingual, responsive collection portal
README.md    Project and deployment notes
```

All modules are educational models, not medical diagnostic tools or personal health advice.
